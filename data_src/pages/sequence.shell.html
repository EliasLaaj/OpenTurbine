Sequence Editor

Edit startup, shutdown, afterburner and simple control rules. Sequence order and parameters are saved together and applied after reboot.

Control Rules

Turn an output on at a threshold, or map an input directly to a variable output. Each output can have one rule, so the result is always predictable.

Outside the selected engine states, the rule releases the output and its normal sequencer/controller command resumes. In a selected state, a false or unavailable input applies the configured off value. Fault hands control to the output's hardware-safe setting.

Fault behavior: If Light Up faults (ignition not confirmed), the afterburner fuel valve closes, its fuel pump stops, and the afterburner igniter turns off immediately. The main engine continues running normally. AB state resets - you can retry from the dashboard.
Light Up Sequence

Runs when the afterburner trigger is activated. Default: check readiness → open the AB fuel valve → start the AB fuel pump → ignite → confirm flame → stabilize. If empty, the built-in default sequence is used.

Light Off Sequence

Runs when the afterburner trigger is released. Default: stop the AB fuel pump → close the AB fuel valve → turn the AB igniter off.
